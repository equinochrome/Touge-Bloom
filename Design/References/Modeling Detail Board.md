# Modeling detail board

Companion to [[Japanese Mountain Reference Board]]. Codex uses these to author assets; Claude uses the landscape references to understand terrain shapes. These are study references, not instructions to copy brand assets or import photographs as game textures.

## R06 — Coupe proportions

![1988 Silvia study reference](https://www.nissan-global.com/EN/HERITAGE_COLLECTION/img/modelDetail/115/low.jpg)

[Source: Nissan Heritage Collection — Silvia Q's](https://www.nissan-global.com/EN/HERITAGE_COLLECTION/silvia_qs.html)

Study long hood, low roofline, wheel placement and restrained two-door proportions. The source lists length 4470 mm, width 1690 mm, height 1290 mm and wheelbase 2475 mm. Use proportions as context; our car is an original fictional design and the game's physics dimensions remain authoritative. This reference does not approve a licensed replica.

## R07 — Sugi tree shape
[Source: Cryptomeria japonica photo gallery](https://commons.wikimedia.org/wiki/Cryptomeria_japonica)

Study full-tree and forest photos, especially Japanese specimens, and compare branching and crown variation. Proposed model target: tapering trunk, irregular narrow crown, visible branch gaps and no stacked cones.

## R08 — Cedar bark close-up

![Cedar bark reference by B.navez](https://upload.wikimedia.org/wikipedia/commons/6/61/Cryptomeria_japonica_bark.jpg)

[Photo description and attribution: B.navez](https://commons.wikimedia.org/wiki/File:Cryptomeria_japonica_bark.jpg)
[CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)

Photographed on Reunion, so this is a species/bark reference, not a Japanese location reference. Study vertical fibrous texture and muted bark color. Create our own texture; do not simply paste this image onto a trunk.

## R09 — Japanese white guardrails
[Photo collection: White guardrails in Japan](https://commons.wikimedia.org/wiki/Category:White_guardrails_in_Japan)
[Broader photo collection](https://commons.wikimedia.org/wiki/Category:Guardrails_in_Japan)

Study folded beam profiles, cylindrical posts, the rail-to-post connection, ground clearance and termination details. Our first module will be a clean straight W-profile beam with cylindrical posts, mounting bolts and an off-white finish. End treatments and curved modules follow later.

## R10 — Mountain pass context
[Route 442 Takehara pass photo, from the guardrail collection](https://commons.wikimedia.org/wiki/File:Route442_takeharatouge.jpg)

Use the road/hillside relationship as a terrain reference. This individual page could not be fetched by the research browser, so inspect the image before using it for precise shape decisions. Do not infer details from its filename alone.

![Retaining-wall reference by Dr.yellow](https://upload.wikimedia.org/wikipedia/commons/7/77/Shinkansen_concrete_retaining_wall_with_rock_bolt.jpg)

## Reference handling
External image embeds need internet. Source pages are retained if image hosting changes. Licenses above apply to the photographs, not a claim that our models have been derived or approved. No reference photograph has been uploaded as a Roblox production asset.

## Model review priorities
Car: silhouette, wheels, glass, lights and original identity.
Cedar: asymmetry, branch gaps, bark direction and base pivot.
Rail: W-profile, post spacing, smooth normals and repeatable ends.
Terrain: coherent mountains and road clearance, authored by Claude as data before integration.
