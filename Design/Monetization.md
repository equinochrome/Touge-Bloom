# Monetization proposal

This is an option for discussion, not an instruction to implement purchases.

## Proposed model
Free driving and earnable performance progression, with optional paid visual expression and garage convenience.

| Offer | Proposed value |
|---|---|
| Cosmetic pack | Coordinated liveries, wheel designs and body-kit variants |
| Garage pass | Extra saved builds and garage display options |
| Supporter pack | Cosmetic badge and a themed visual set |

Avoid paid drift multipliers or exclusive dominant performance upgrades. Prices are intentionally undecided; first learn what players value.

## Reasons to return
A daily shared seed, personal bests, car meets, drift challenges and later ghost runs. Ship these only after the basic driving loop is enjoyable.

## Business measurements
Track return visits, session length, purchase conversion, net earnings and development/asset/promotion costs. Revenue alone does not establish profitability.

## Current Roblox sources
Checked 2026-10-10:
- [Monetization options](https://create.roblox.com/docs/production/monetization): passes for permanent benefits; developer products for repeat purchases.
- [Regional pricing](https://create.roblox.com/docs/production/monetization/regional-pricing): price adjustment by economic region.
- [Creator Rewards](https://create.roblox.com/docs/creator-rewards): potential supplemental earnings for qualifying activity.

Verify platform requirements again when implementation starts.
