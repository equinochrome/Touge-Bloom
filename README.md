# Car Game: Scenic Drift

A Roblox drift game set on seeded, procedurally generated scenic circuits. Rojo 7.7.1 syncs the code into Studio.

- [PLAN.md](PLAN.md): the full design and the phased plan
- [docs/PHASE0.md](docs/PHASE0.md): Studio setup, test steps and the checklist for the current phase

## Quick start

```bash
rojo build -o "Car Game.rbxlx"   # once, then open the file in Studio
rojo serve                        # live-sync src/ into Studio (Plugins > Rojo > Connect)
```
